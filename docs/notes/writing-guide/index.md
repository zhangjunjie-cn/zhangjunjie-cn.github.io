## 写一篇新文章的四步

1. 在对应目录新建 `.md`，照 [文章模板](./02-writing.md) 填 frontmatter。
2. 正文用 [容器语法](./04-containers.md) 区分提示、警告、可折叠内容。
3. 图片和视频按 [图片与视频](./05-media.md) 的路径规则放置，视频先过一遍 `pnpm video`。
4. `pnpm dev` 里实际点一遍（尤其是视频能起播、能拖动），再提交。
