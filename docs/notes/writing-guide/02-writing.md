# 新建文章

文章放进 `docs/ai/` 这类普通目录即可，左侧目录按目录自动生成，不需要改配置。照下面这个模板起头：

```md
---
title: 文章标题
date: 2026-07-07
updated: 2026-07-08
# 供「最后更新于」使用，必须带时区
lastUpdated: 2026-07-08T10:30:00+08:00
description: 一句话摘要，用于 SEO 和文章卡片
tags:
  - Markdown
---

# 文章标题

<NolebasePageProperties />

正文第一段……

## 小标题
```

## 字段分工

| 字段 | 作用 | 不填会怎样 |
|---|---|---|
| `title` | 侧栏标题、文章卡片标题 | 退回正文的一级标题 |
| `date` | 归档页排序依据 | 这篇**不会进归档列表**，也不显示日期 |
| `description` | 文章列表摘要、搜索结果 | 卡片上一片空白 |
| `tags` | 标签页聚合、卡片左上角的图标 | 没有标签胶囊，图标退回默认 |
| `updated` | 显示「更新于」 | 只显示创建日期 |
| `lastUpdated` | 「最后更新于」，精确到时间 | 用 git 提交时间兜底 |
| `icon` | —— | 当前**没有任何代码读取它**，填了也不生效 |

:::warning 只有 tags 决定图标
文章卡片的图标取自 `tags` 的第一个值，去 `tagIcons.ts` 里查表，查不到就用默认图标。`icon:` 是历史遗留字段，写了没有效果。
:::

## 文件名就是链接

`docs/ai/qq-agent-mail.md` 会生成 `/ai/qq-agent-mail`。文件名用英文短横线，改文件名等于改链接，站内已有引用会一起断掉。

:::tip 路径规则
`docs/public/` 映射到站点根路径，所以 `public/video/a.mp4` 写作 `/video/a.mp4`，**不要**带 `public`。详见 [图片与视频](./05-media.md)。
:::

## 不要写 layout

普通文章不写 `layout`，写错会变成首页那种整页布局。可用的布局只有 `home`、`tags`、`posts`、`case`、`travel`，分别对应首页、标签页、归档页、旅途页和游记详情。

## 正文结构

- 一级标题只出现一次，和 `title` 保持一致。
- `<NolebasePageProperties />` 紧贴一级标题下方，负责渲染日期与标签胶囊。
- 二级标题用来分节，左侧目录会自动抓取，标题写得短一些更好读。
