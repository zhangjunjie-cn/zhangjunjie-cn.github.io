md

title: 文章标题
date: 2026-07-07
updated: 2026-07-08
# 供「最后更新于」使用，必须带时区
lastUpdated: 2026-07-08T10:30:00+08:00
description: 一句话摘要，用于 SEO 和文章卡片
tags:
  - Markdown
---

## 小标题

字段分工 ​

字段作用不填会怎样
title侧栏标题、文章卡片标题退回正文的一级标题
date归档页排序依据这篇不会进归档列表，也不显示日期
description文章列表摘要、搜索结果卡片上一片空白
tags标签页聚合、卡片左上角的图标没有标签胶囊，图标退回默认
updated显示「更新于」只显示创建日期
lastUpdated「最后更新于」，精确到时间用 git 提交时间兜底
icon——当前没有任何代码读取它，填了也不生效
只有 tags 决定图标

文章卡片的图标取自 tags 的第一个值，去 tagIcons.ts 里查表，查不到就用默认图标。icon: 是历史遗留字段，写了没有效果。

文件名就是链接 ​

docs/ai/qq-agent-mail.md 会生成 /ai/qq-agent-mail。文件名用英文短横线，改文件名等于改链接，站内已有引用会一起断掉。

路径规则

docs/public/ 映射到站点根路径，所以 public/video/a.mp4 写作 /video/a.mp4，不要带 public。详见 图片与视频。

不要写 layout ​

普通文章不写 layout，写错会变成首页那种整页布局。可用的布局只有 home、tags、posts、case、travel，分别对应首页、标签页、归档页、旅途页和游记详情。

正文结构 ​

  • 一级标题只出现一次，和 title 保持一致。
  • <NolebasePageProperties /> 紧贴一级标题下方，负责渲染日期与标签胶囊。
  • 二级标题用来分节，左侧目录会自动抓取，标题写得短一些更好读。
